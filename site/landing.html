Para desenvolvedores

Primeira impressão em cinco minutos.

  1. Instale o EasyPrintRode o assistente e escolha o Simulador se ainda não tiver impressora.
  2. Copie o SDKeasyprint.js, um arquivo sem dependências, com .d.ts para TypeScript.
  3. Conecte e imprimaNa primeira vez, o lojista clica em Permitir. Depois disso, não pergunta mais.
  4. Ou deixe a IA fazerEntregue o EASYPRINT_AI.md ao Claude, ChatGPT, Cursor ou Copilot.
const printer = EasyPrint.connect({
  appName: 'Minha Loja',
  routes: { pedido: 'Pedidos', etiqueta: 'Etiquetas' },
});

// cupom na térmica
await printer.print(
  EasyPrint.receipt()
    .title('PEDIDO #4821')
    .item(1, 'Pizza Calabresa G', 'R$ 62,90', 'sem cebola')
    .total('TOTAL', 'R$ 94,70')
    .qr('https://loja.com/p/4821')
    .cut(),
  { route: 'pedido' }
);

// etiqueta do marketplace e DANFE
await printer.printRaw(zpl, { route: 'etiqueta' });
await printer.printPdf('/notas/4821.pdf');

Segurança

Simples para o lojista, rígido por dentro.

Um programa que imprime no computador da loja precisa ser difícil de abusar. Cada camada foi coberta por testes automatizados, incluindo ataques simulados.

Só localEscuta apenas em 127.0.0.1. Nenhuma porta fica aberta para a rede.
Permissão por siteCada site novo precisa de um clique em Permitir. O endereço vem do navegador e não pode ser falsificado.
Assinado e cifrado de ponta a pontaNa nuvem, cada impressão é assinada (Ed25519) e cifrada (AES-256-GCM) só para o computador da loja. O relay não lê nem forja pedidos.
Anti-replay e validadeCada trabalho imprime uma única vez e expira. Um trabalho da Loja A é recusado na Loja B.
Gaveta protegida e limite de impressõesNenhum site ou sistema abre a gaveta sem o lojista liberar. Um limite por minuto segura um site invadido.
HTML isoladoHTML é renderizado sem scripts, sem acesso à rede local e sem acesso aos arquivos do computador.
Downloads verificáveisCada release publica os hashes SHA-256. O instalador do Linux confere antes de instalar.
Código de conexão de uso únicoUma foto do código depois de conectado não serve para nada.
